# MCD 조건부 분할매수 Shorts v8 제작 브리프

기준일은 2026-08-31 미국 종가다. 이 영상은 교육 목적의 기업 분석과
조건부 시나리오이며, 확정 수익·개인 맞춤 투자자문·개별 매수 지시가 아니다.
`narration.v8.ko.txt`는 MPT 음성이 이미 생성된 `narration.v6.ko.txt`와
텍스트를 동일하게 유지한다. 새 TTS를 만들지 않고 기존 음성을 재사용한다.

## 편집 목표

- 최종 영상: 1080×1920, 30fps, 약 58.5초, 정확히 14개 장면.
- 장면 경계(초): `0, 4.0, 7.45, 10.95, 15.15, 19.75, 23.95, 29.05,
  33.3, 38.35, 41.55, 45.75, 50.0, 54.0, 58.5`.
- 한 장면에 하나의 주장과 하나의 주동작만 둔다. 카메라 변화와 지연된
  보조동작을 붙이되, 장식 효과를 정보처럼 사용하지 않는다.
- 내레이션·검토 SRT·정확한 숫자·축·출처는 결정론적 MPT/Pillow/FFmpeg
  레이어다. 생성형 영상 모델은 사용하더라도 2~4초 무문자 plate에만 쓴다.
- 영상의 첫 장면은 QQQ 상승과 MCD 하락의 괴리를 즉시 보여주고, 마지막은
  조건부 확대와 취소 조건을 함께 보여주며 루프 가능하게 닫는다.

## 14개 장면의 시각 계약

세로 최종본은 현재 v8 renderer의 720×1280 내부 캔버스를 1080×1920으로
확대한다. 건물·지도·장비·카드가 서로 침범하지 않도록 `storyboard-v8.md`의
lane을 고정한다.

- 생성 plate에는 한국어, 숫자, 축, 범례, 티커, 로고를 넣지 않는다.
- 금색 아치는 설명용 geometry로만 합성하고, 외부 MCD 로고 파일이나 타인의
  브랜드 영상을 복제하지 않는다.
- 세계지도는 하나의 vector projection에 노드와 연결선을 순차적으로 그린다.
  노드는 글로벌 네트워크를 설명하는 장치이지 46,028개 매장의 정확한 좌표가
  아니다.
- 부동산 장면은 `LAND → BUILDING → EQUIPMENT`를 수직·시간 순서로 분리하고,
  `RENT`와 `ROYALTY` 카드를 오른쪽 고정 lane에 둔다. 땅·건물·장비를 한
  위치에 겹쳐 그리지 않는다.
- 그래프·배당·beta는 수치 카드와 선을 별도 lane에 두며, 자막이 있는 하단
  lane에는 데이터 카드·출처·로고를 넣지 않는다.
- 모든 장면은 camera + primary action + delayed secondary action을 가져야
  하며, 1~3초마다 의미 있는 상태 변화를 만든다. glow·particle·금고·파이프
  같은 무관한 장식은 사용하지 않는다.

## 안전영역과 arrange 계약

좌표는 내부 720×1280 기준이며 최종 1080×1920에서는 1.5배로 환산한다.

| lane | 내부 좌표 | 역할 |
|---|---|---|
| `header_rect` | `(0,0)-(720,74)` | 고정 `MCD · INVESTMENT CASE`와 데이터 기준일 |
| `title_rect` | `(46,100)-(680,230)` | eyebrow + 최대 2줄 장면 제목 |
| `content_rect` | `(54,272)-(666,944)` | 건물·지도·그래프·데이터 카드. 서로의 `reserved_rects`와 충돌 금지 |
| `source_rect` | `(48,948)-(672,990)` | 한 줄 출처. 수치·카드와 분리 |
| `caption_rect` | `(38,1002)-(682,1182)` | MPT 자막 캡슐. 외부 플랫폼 UI를 고려한 하단 안전영역 |
| `bottom_dead_zone` | `(0,1183)-(720,1280)` | 플랫폼 버튼·진행바가 덮을 수 있어 핵심 정보 금지 |

텍스트 bbox가 `header_rect`, `title_rect`, `content_rect`, `source_rect`,
`caption_rect`를 동시에 침범하면 렌더를 통과시키지 않는다. 숫자·한글은
`source-ledger → 검토 대본/SRT → Pillow/FFmpeg` 순서로만 생성한다.

## 제작 스택과 권리 경계

- 기본 경로는 검증된 MoneyPrinterTurbo prepared-local + 기존 한국어 음성 +
  Pillow/FFmpeg 결정론적 모션이다. 이번 패키지는 renderer·QA·verification을
  수정하지 않는다.
- HF SCoPE/Wan2.2 등은 외부 NVIDIA/허가된 Space에서만 2~4초 무문자 plate
  PoC 후보다. 모델 revision·Space stage·라이선스·쿼터·업로드 보관을 확인하기
  전에는 실행하지 않는다.
- integrated HF/Reddit/GitHub 보고서는 camera contract, frame-driven motion,
  source ledger, safe-zone, no-text plate 원칙의 참고자료다. Reddit 자기보고나
  조회수는 MCD 투자 사실·영상 품질의 증거로 사용하지 않는다.
- 폰트·음성·지도 타일·모델·생성물·MCD 상표는 MoneyPrinterTurbo 또는
  renderer 라이선스와 별도다. 영상 게시 전 각각의 권리를 확인한다.
- YouTube·Instagram·X에 자동 게시하지 않는다. 최종 산출물은 사람 검수 후
  사용자가 직접 게시한다.

## 완료 기준

1. `narration.v8.ko.txt`와 v6 텍스트가 동일하다.
2. `storyboard-v8.md`가 14개 scene_id와 위 15개 boundary(0 포함)를 정확히
   사용한다.
3. `subtitle.v8.srt`는 14개 cue이고, 마지막을 제외한 모든 cue가 최대 2줄이다.
4. 모든 scene의 claim_id가 `sources-v8.md`의 원자료·계산·해석 구분과 연결된다.
5. 렌더 후에는 scene boundary, dense caption, bbox collision, platform safe-zone,
   fps·freeze·full decode를 확인한다. 이 문서 작성만으로 영상 생성·검증 완료를
   주장하지 않는다.
