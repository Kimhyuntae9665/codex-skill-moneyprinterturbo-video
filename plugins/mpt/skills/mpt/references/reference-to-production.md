# 레퍼런스를 재현 가능한 제작 결정으로 바꾸기

외부 AI 영상·갤러리를 참고해 재질, 카메라, 편집, 소리를 개선할 때 읽는다. 기존 `editorial-tempo.md`의 오디오 선행 편집과 장면 검수를 보완한다. Blender 작업에서는 `cinematic-mechanism-shorts/references/reference-to-blender-direction.md`의 공간·연기·연속성 규칙을 유지한다.

## 결함에 맞는 자료를 고른다

먼저 이번 장면에서 부족한 점 하나를 적는다. 예: ‘카메라는 움직이는데 무엇이 드러났는지 모르겠다’, ‘금속이 플라스틱처럼 보인다’, ‘충돌 순간과 효과음이 어긋난다’. 그 문제를 해결하는 구간을 찾는다. 모든 사이트 방문이나 특정 개수 수집을 매번 의무화하지 않는다. 이미 검수한 자체 장면도 레퍼런스로 재사용한다.

| 발견 경로 | 찾아볼 요소 | 확인 범위와 사용 경계 |
|---|---|---|
| [Runway Watch](https://app.runwayml.com/watch) | 가려진 대상 공개, 카메라 이동, 공간 규모, 전환 | 공개 작품 목록을 확인했다. 개별 작품의 해당 구간을 재생한 뒤에만 움직임을 분석한다. 갤러리 등재는 사용 모델·제작법의 증명이 아니다. |
| [Reddit r/aivideo](https://www.reddit.com/r/aivideo/) | 편집 아이디어, 제작자의 시행착오, 도구 설명 | 피드·제작 토론을 발견 경로로 사용한다. 제목·플레어·업보트는 구현 성공이나 시청 유지율의 증거가 아니다. |
| [Curious Refuge AI Film Gallery](https://curiousrefuge.com/ai-film-gallery) | 이야기 전개, 장면 사이 연결, 음성·환경음·음악 관계 | 공개 갤러리를 확인했다. 음향 평가는 실제 재생·청취한 구간에 한정한다. 목록 열람만으로 작품을 감상했다고 기록하지 않는다. |
| [Civitai video gallery](https://civitai.com/videos) | 공개되어 있다면 재질 표현과 생성 설정 | 추천 게시물에서 얻은 후보다. 2026-09-22 조사에서는 브라우저 보안 정책으로 차단되어 직접 검증하지 못했다. 필수 경로로 삼지 않으며, 차단 시 다른 접속 방식으로 우회하지 않는다. |

검색은 현재 결함을 해결할 구현과 시험 기준이 정해지면 끝낸다. 접근이 막히면 허용된 다른 자료나 로컬 레퍼런스로 계속한다. 사이트 추천을 새 유료 API·모델·플러그인 설치 요구로 바꾸지 않는다.

갤러리 분석을 넘어 이미지·I2V·TTS·음악 생성 서비스 자체를 검토한다면 [생성 도구 선택 기준](generative-component-selection.md)을 적용한다. 한국어 음성 비교와 음악 브리프를 먼저 정하고, 무료 체험 가능 여부와 최종 출력 이용 조건을 구분한다.

## 관찰, 제작자 설명, 자체 시험을 분리한다

기존 `reference-breakdown.md` 또는 `story-visual-map.md`에 필요한 행만 보탠다. 같은 내용을 여러 문서에 복제하지 않는다.

- **직접 관찰:** 원작 URL, 관찰일, 구간, `본문만 / 정지 프레임 / 연속 재생 / 실제 청취` 중 실제 수행 범위와 보이는 변화.
- **제작자 설명:** 공개된 도구·설정·워크플로우의 원문 위치. 결과만 보고 모델, LoRA, 프롬프트, 시드를 추정하지 않는다. 제작자가 주장한 것과 실행으로 확인한 것을 구분한다.
- **우리 구현:** 적용할 요소 하나, 현재 장면의 주체·행동에 맞춘 제어, 기대 결과, 렌더 파일·구간과 채택/수정/기각 이유.

생성형 결과의 재현이 필요한 경우에만 공개된 모델/버전, LoRA/강도, 프롬프트·negative prompt, 시드, 크기·fps·길이, sampler·steps·CFG, 참조 이미지·제어 입력, 후편집·업스케일·보간 중 해당 항목을 기록한다. 누락은 `unknown`으로 둔다. 프롬프트와 시드만 같아도 결과가 재현된다고 약속하지 않는다. 다운로드가 필요하면 모델 라이선스와 참조 자산 이용 조건을 각각 확인한다. 열람 권한은 최종 영상 삽입 권한이 아니다.

## 감상평 대신 렌더러 제어로 옮긴다

| 배울 요소 | 실제 제작 결정 | 검수할 결과 |
|---|---|---|
| 재질의 윤기·질감 | Blender roughness, 표면 디테일, 광원 크기·각도, 반사 환경을 해당 물체에 맞춰 조정 | 동일 구도에서 소재가 구별되고 하이라이트가 형태를 지우지 않는가 |
| 카메라 reveal | 무엇을 가릴지, 카메라 위치·경로, 렌즈/FOV, 최종 구도와 읽는 시간을 결정 | 움직인 뒤 새로운 관계나 대상이 실제로 드러나는가 |
| 컷의 타격감 | 완성된 음성의 의미 종료점·접촉·시선·동작 연결 중 컷의 이유를 선택 | 수치·단위나 문장이 잘리지 않고, 다음 컷에서 상태가 이어지는가 |
| 소리의 긴장·해소 | 행동 직전 기대음, 접촉 순간 효과음, 결과의 잔향·환경음과 BGM ducking을 필요한 곳에 배치 | 화면 사건과 소리가 맞고 나레이션이 명료한가; 실제 청취 여부를 별도 기록 |

예를 들어 대기열이 긴 CPU 장면은 카메라가 뒤로 빠지며 처리 대기 중인 작업을 드러낼 수 있다. 통로가 닫히는 장면은 물체가 멈추는 순간에 접촉음을 맞출 수 있다. 이는 독자적인 연출 예시이며 특정 회사의 실제 시스템이나 검증된 렌더 결과가 아니다. 소리·광택·카메라 움직임으로 잘못된 기업 관계나 물리적 연결을 감추지 않는다.

## 기존 짧은 시험에 통합한다

새 기법의 효과나 비용이 불확실할 때만 기존 훅/고난도 구간 시험에 넣는다. 전체 영상을 먼저 렌더하거나 별도의 중복 QA 단계를 만들지 않는다. 가능하면 같은 구도에서 문제와 관련된 변수 하나를 바꾼다.

채택 기준은 `이야기가 더 잘 읽힘`, `물체·접촉·상태 연속성 유지`, `휴대폰 크기 가독성`, `소리와 사건의 일치`다. 추가 렌더 시간·VRAM은 측정했을 때만 수치로 적는다. 보기 좋지만 설명을 방해하거나 비용만 늘리는 효과는 기각한다. 미재생·미청취·미렌더 상태는 그대로 남기며, 규칙 추가만으로 품질 향상이나 조회수 상승이 검증되었다고 보고하지 않는다.

## 이 지침의 출처와 확인 범위

2026-09-22에 [꼬마봇의 추천 게시물](https://x.com/BBBang9900/status/2099513501832331735) 본문과 첨부 이미지를 확인했다. 게시물은 위 네 곳을 역할별 참고 자료로 추천하며, 첨부는 반응 이미지다. 구체적인 생성 레시피·워크플로우나 제작 시연 영상은 제공하지 않는다. Runway·Reddit·Curious Refuge는 갤러리/피드 수준에서 확인했으며 개별 작품의 연속 재생·청취 분석은 수행하지 않았다. 위 구현·검수 규칙은 기존 제작 흐름에 맞춘 자체 설계다.
