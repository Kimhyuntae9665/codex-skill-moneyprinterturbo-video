# 생성 도구는 부족한 제작 요소에만 붙인다

외부 이미지·영상·TTS·음악 도구를 검토할 때 사용한다. 목적은 기존 제작에서 부족한 한 요소를 개선하는 것이다. Blender 중심 장면 제작과 MPT의 오디오 선행 편집·자막·조립·썸네일·검수 흐름을 유지한다. 서비스 이름을 추가한 것을 설치·연동·품질 검증 완료로 표현하지 않는다.

## 역할과 시험 단위를 먼저 정한다

| 후보 | 우리 제작에서 검토할 역할 | 최소 비교 시험과 채택 기준 |
|---|---|---|
| Leonardo.ai 등 이미지 생성기 | 장면 룩 개발, 분위기·재질 레퍼런스, 필요한 보조 이미지 | 동일한 장면 요구로 구도·색·소재를 비교한다. 실제 로고·제품·수치·기업 증거 이미지를 생성물로 대체하지 않는다. 컨셉 이미지는 실제 촬영 자료와 구분한다. |
| Runway 등 I2V 생성기 | 기존 제작으로 해결하기 어려운 짧은 분위기 컷 | 승인한 시작 이미지, 변할 동작 하나, 고정할 물체·배경을 정한다. 처음·중간·끝과 연속 재생에서 형태·접촉·카메라 의도를 확인한다. 구조 설명은 기존 Blender로 유지하고, 변형된 클립은 효과로 숨기지 않는다. |
| ElevenLabs 등 TTS | 기계적인 낭독, 한국어 강세·질문·반전 표현 개선 | 기존 TTS와 같은 한국어 구간을 합성·청취해 발음·완급·명료도를 비교한다. 더 감정적이라는 이유만으로 숫자나 고유명사를 틀린 음성을 채택하지 않는다. |
| Suno 등 음악 생성기 | 영상 고유의 긴장·해소 리듬과 짧은 음악 모티프 | 기존 사용 가능한 BGM과 같은 구간에 믹스해 비교한다. 보컬 없는 반주를 우선하고, 목소리와 경쟁하거나 중요한 문장을 덮으면 수정·기각한다. |

위 후보의 제품별 지원 기능은 실행 직전 공식 문서와 실제 계정에서 확인한다. 이미지 생성·수정은 현재 세션에 지정된 이미지 도구 규칙을 우선하며, 이 후보 목록을 그 규칙의 우회 근거로 사용하지 않는다. 기존 로컬 GPU·Blender·권리가 확인된 오디오가 요구를 만족하면 새 서비스를 쓰지 않는다.

반복 인물을 쓰는 보조 이미지/I2V는 [캐릭터 시트와 인물 검수 기준](../../cinematic-mechanism-shorts/references/reference-to-blender-direction.md)의 4절을 적용한다. 시트의 작은 얼굴을 확대 원본으로 쓰지 않고, 동일 인물 유지·선명도·움직임의 안정성을 따로 평가한다. 얼굴 참조 훼손이 품질을 높인다는 SNS 주장을 기본 전처리로 옮기지 않는다.

## 음성 비교는 광고 문구 대신 같은 대본으로 한다

대표 구간에는 질문형 훅, 기업/제품명, 기간을 포함한 숫자, 반전 또는 결론을 포함한다. 본편 전체를 여러 엔진으로 먼저 생성하지 않는다.

- 사용자 지정 속도가 없으면 기존 1.30배 선호를 유지한다. 엔진의 속도 슬라이더 값이 같은 배속을 뜻한다고 가정하지 말고 실제 발화 길이·명료도로 맞춘다. 엔진 속도 조정과 후처리 배속을 중복 적용하지 않는다.
- 비슷한 음량과 목표 속도로 비교해 단순히 크거나 느린 음성이 좋아 보이는 착시를 줄인다. 속삭임·과한 숨소리·감정 태그를 모든 문장에 넣지 않는다.
- 지원이 확인된 모델별 발음/스타일 제어만 사용한다. SSML이나 감정 태그가 모든 TTS에 통한다고 가정하지 않는다.
- 음성 선택 후 무음 편집과 타임스탬프를 다시 확정한다. 이전 엔진의 컷·자막 시간을 재사용하지 않는다.
- 기본은 이용 가능한 허가된 합성 음성이다. ‘1분 클론’이라는 소개만으로 실제 사람의 음성을 수집·업로드·복제하지 않는다. 사용자가 특정 음성 복제를 요청했을 때만 해당 목소리의 동의·권한과 서비스 조건을 확인한다.

## 음악도 장면용 브리프를 쓴다

기존 사운드 계획에 `역할 / 악기·질감 / 에너지 변화 / 비워둘 대사 구간 / 반전 지점 / 끝맺음`을 적는다. 단순히 ‘웅장한 음악’이나 장르명만 넣지 않는다.

독자적 브리프 예시: ‘보컬 없는 짧은 전자음악. 도입은 낮은 펄스, 문제를 설명할 때는 악기를 줄이고, 해결 장면에서만 짧게 확장한다. 숫자를 말하는 구간에는 두드러진 리드 멜로디를 피하고, 결론은 짧게 끝낸다.’ 특정 곡·아티스트 복제 지시가 아니다.

생성기가 정확한 타임코드를 따랐다고 가정하지 않는다. 실제 트랙을 듣고 편집·페이드·ducking으로 완성된 음성에 맞춘다. 음악 생성은 사건별 효과음 설계를 대신하지 않는다. Suno에서 전체 노래를 생성할 수 있다는 이유로 숏츠에 보컬과 가사를 의무화하지 않는다.

## 무료 체험과 최종 사용 가능성을 따로 판단한다

도입 후보마다 기존 자산 기록에 `서비스·모델 / 실제 플랜 / 생성·다운로드일 / 자산 ID / 이용 조건 URL·확인일 / 워터마크 / 공개 여부 / 최종 사용 가능 여부` 중 해당하는 값을 남긴다. 웹 무료 크레딧이 API에도 적용되거나 자동화 권한을 제공한다고 가정하지 않는다. 소비한 크레딧·실패·재생성·편집 시간을 합쳐 사용 가능한 출력물 기준으로 비용을 비교한다. 측정 전에는 비용 우위를 주장하지 않는다.

2026-09-22 공식 자료 확인값이며 영구 조건이 아니다. 실제 실행·공개 전 변경 여부를 확인한다.

- **Leonardo:** [공식 상업 이용 안내](https://intercom.help/leonardo-ai/en/articles/8044018-commercial-usage)는 무료 사용자도 자기 생성물을 상업적으로 사용할 수 있다고 설명하지만, 무료 생성물의 공개·재사용 조건을 함께 명시한다. 비공개 작업을 무료 플랜에 올려도 비공개로 유지된다고 가정하지 않는다.
- **Runway:** [무료 플랜 안내](https://help.runwayml.com/hc/en-us/articles/50404627334547-Free-plan-details)는 일회성 125크레딧, 제한된 모델, 워터마크를 설명한다. 매일 충전되는 제작 자원으로 계산하지 않는다. 실제 계정의 할당·기능을 확인하고, 최종 사용 시 별도로 이용 권한을 확인한다.
- **ElevenLabs:** [공식 게시·사용 안내](https://help.elevenlabs.io/hc/en-us/articles/13313564601361-Can-I-publish-the-content-I-generate-on-the-platform)는 무료 출력의 상업 사용을 허용하지 않으며, 비상업적 공개에도 출처 조건이 있다. 유료라도 제품별 조건·베타 제외 여부를 확인한다. 무료 데모를 수익화용 최종 음성으로 섞지 않는다.
- **Suno:** [2026-09-03 적용 변경 안내](https://suno.com/blog/suno-updates-tos)는 체험 다운로드의 개인용 한정과 유료 플랜 다운로드의 상업 이용을 구분한다. 이전 생성일 기준 FAQ와 변경된 다운로드 기준을 혼합하지 않는다. 해당 곡·계정에 적용되는 최신 약관과 생성/다운로드 상태를 확인하며, 불명확한 곡은 권리가 확인된 기존 BGM으로 대체한다.

무료 크레딧 유무, 다운로드 가능, 상업적 사용 허용, 독점적 권리, 제3자 권리 문제 없음은 서로 다른 판단이다. ‘AI로 직접 만들었으니 저작권 걱정 없음’이라는 문구를 납품 근거로 쓰지 않는다. 이 스킬 수정 요청 자체는 가입·구독·유료 생성·음성 업로드 요청이 아니다. 기존에 사용이 승인된 도구·예산은 그 범위 안에서 계속 활용한다.
