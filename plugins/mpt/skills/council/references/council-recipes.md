# Council Recipes

Use the matching recipe to shape the council output. Keep advisor comments short and synthesize into one practical answer.

Every recipe inherits the runtime contract in `../SKILL.md`: five independent GPT-5.6 Luna advisors at max reasoning and fast service must pass the five-of-five completion gate before GPT-5.6 Sol at max reasoning performs verification and synthesis. A recipe changes content emphasis only; it never weakens, replaces, or simulates that runtime contract.

## 1. General Council

Use for open-ended advice, strategy, planning, or recommendations.

Output:
- Each advisor's brief view
- Key disagreements
- Final practical answer
- Clear next steps

## 2. Choose Between Options

Inputs:
- Options
- Goal
- Constraints: budget, time, skills, risk tolerance, deadlines

Output:
- Best option
- Ranked list
- Why it wins
- Risks to watch
- First 5 steps

Decision rule: rank by goal fit first, then feasibility, downside risk, reversibility, and speed to feedback.

## 3. Improve A Social Media Post

Inputs:
- Platform
- Target audience
- Goal: comments, sales, education, clicks, trust
- Draft post

Advisor emphasis:
- Strategist: goal and positioning
- Skeptic: claims, backlash, ambiguity
- Creative: hooks, framing, memorability
- Operator: structure, length, format
- Audience Advocate: clarity, value, CTA fit

Output:
- What works
- Weak points
- 3 stronger hooks
- Improved version
- Short version
- Strong CTA options

## 4. Build A 7-Day Action Plan

Inputs:
- Goal
- Current situation
- Daily available time
- Skill level
- Resources: tools, budget, team

Output:
- 7-day plan
- Daily tasks
- Time estimate per task
- Easy version
- Ambitious version
- Mistakes to avoid

Rule: every day should produce visible progress or feedback.

## 5. Compare AI Tools

Inputs:
- Tools
- Use case
- Skill level
- Budget
- Most important criterion: ease, quality, speed, price, privacy

Output:
- Comparison table
- Best overall tool
- Best beginner tool
- Best budget tool
- Tool to avoid
- Final recommendation

Rule: if current pricing, model quality, or product features matter, verify recent facts before ranking.

## 6. Create A Content Calendar

Inputs:
- Niche
- Audience
- Goal
- Platforms
- Posting frequency
- Style

Output:
- Content pillars
- 30-day calendar
- Hook for each post
- Post format
- CTA ideas
- Top 5 strongest post ideas

Rule: balance reach, trust, conversion, and repeatable production workload.

## 7. Validate A Business Or Side-Hustle Idea

Inputs:
- Idea
- Target customer
- Pain point
- Price
- Sales method
- Resources: time, money, skills, audience

Output:
- Score from 1 to 10
- Strengths
- Weaknesses
- Ideal customer
- Better offer wording
- 3 demand tests
- First action step

Decision rule: demand evidence beats enthusiasm. Prefer cheap tests before building.

## 8. Make A Difficult Decision

Inputs:
- Decision
- Options A/B/C
- What matters most: values and goals
- Biggest fear
- Deadline

Output:
- Pros and cons of each option
- Hidden risks
- Emotional factors
- Practical factors
- Decision matrix
- Final recommendation
- Low-risk next step

Rule: highlight reversible vs irreversible parts of the decision.

## 9. Turn Messy Notes Into A Clear Plan

Inputs:
- Notes
- Goal
- Audience
- Deadline

Output:
- Clean summary
- Key themes
- Action items
- Priority order
- Simple timeline
- Polished final version
- Questions still unanswered

Rule: preserve useful raw ideas but remove duplication and unclear phrasing.

## 10. Create A Beginner-Friendly Learning Plan

Inputs:
- Topic
- Current level
- Reason for learning
- Time per week
- Learning style
- Target: 30 days, first project, interview, skill building

Output:
- 30-day roadmap
- Weekly milestones
- Daily practice tasks
- Key concepts explained simply
- Practice projects
- Progress checklist
- Final project idea

Rule: bias toward practice and small projects over passive consumption.
