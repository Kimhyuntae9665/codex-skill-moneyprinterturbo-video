# Running the bounded local proof

The script creates an ORIGINAL conceptual cold-plate scene with five cameras, an opening cover, connected serpentine lanes, symbolic flow markers, connected hoses and generic server-room context. It is not a general text-to-video engine, engineering simulation or exact NVIDIA product model.

Requirements: Blender with Python/bpy. Tested with Blender 5.2.1 LTS on Windows. It does not require external 3D assets or paid generation. Cycles CPU rendering can be slow. Start with stills, then a short frame range; do not confuse a built .blend file with a rendered video.

```powershell
blender -b -t 6 --python '.\scripts\cooling_proof.py' -- build --out '.\work\cooling-proof'
```

Use your actual Blender/script paths. `--out` is a project output directory and is created if absent. The script replaces the scene inside its new background Blender process, not an open interactive project. `build` saves `cooling-proof.blend`; `stills` additionally renders representative PNGs; `render` renders the full 576-frame, 24 fps animation at 720×1280 with six Cycles samples and denoising. These are smoke-test settings, not a reference-quality guarantee.

Render a small frame range from the saved file:

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' -b '.\work\cooling-proof\cooling-proof.blend' -t 6 -s 160 -e 232 -a
```

Encode the PNG sequence with your installed FFmpeg:

```powershell
ffmpeg -framerate 24 -start_number 160 -i '.\work\cooling-proof\frames\f_%04d.png' -frames:v 73 -c:v libx264 -crf 19 -pix_fmt yuv420p '.\work\cooling-proof\motion-proof.mp4'
```

No audio or text is generated by the Blender script. Add the actual edited Korean narration in your production pipeline, retime each semantic shot to the audio, and compose captions after the picture. Keep a label for the conceptual model and symbolic flow markers. The separate `validate_shots.py` checks JSON structure, not physical correctness.

The lesson from this implementation is to prove cameras and topology first. Improving the material render with an image model is a separate step, and must preserve divider count, ports and connection direction. A generated still does not prove temporal consistency in video.

Run the rig-specific geometry check before rendering:

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' -b '.\work\cooling-proof\cooling-proof.blend' --python '.\scripts\audit_cooling_geometry.py' -- --out '.\work\cooling-proof\geometry-audit.json'
```

Use the actual installed script path. This checks five divider attachments, turn clearance and visible tracer positions against nominal bounds over frames 155–352. It does not verify fluid dynamics or the interior bores of schematic hose connectors, and does not inspect captions or camera occlusion. Keep the JSON scope and limitations with the result.
