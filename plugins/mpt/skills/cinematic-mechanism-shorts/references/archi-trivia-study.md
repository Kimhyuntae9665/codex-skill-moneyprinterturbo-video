# 새 참고 채널 조사: 신기한건축이야기

**후속 확장 완료:** 아래는 최초 3편의 일부 시점 조사 기록이다. 현재 관찰 범위는 [12편 전 구간 표본과 4개 세부 구간 연구](archi-trivia-12-study.md)로 확장했다. 제작에는 [연출 도구함](causal-staging-library.md)을 적용한다. 아래의 '12편 전체를 보지 않았다'는 문장은 최초 조사 시점의 범위이며 현재 확장 기록과 구분한다.

관찰일 2026-09-06, 로그인된 Chrome의 공개 페이지와 실제 재생 화면을 확인했다. 전수 분석이나 전체 청취 보고가 아니다.

## 출처와 확인 범위

- 요청한 [X 원문](https://x.com/mad_dogdebt/status/2096376375389360247)은 영상이 아니라 Instagram 프로필 이미지와 채널 소개 글이다. 글과 이미지의 `archi_trivia1`을 직접 읽었다. 관찰 당시 게시물 표시는 좋아요 45, 재게시 9, 조회수 8,748이었다. 이는 당시 공개 수치이며 유지율 증거는 아니다.
- 연결 채널은 [신기한건축이야기 / archi_trivia1](https://www.instagram.com/archi_trivia1/). 프로필에서 게시물 20개·팔로워 1.2만 표시와 건축/구조를 3D 모션으로 설명한다는 자기소개를 확인했다. 이전 YouTube `신비한_건축사전_1`과 혼동하지 않는다.
- [제작자 공개 글](https://x.com/nowlovepan/status/2096386930825134268)은 기존 GPT5.6 기반 영상 자동화 워크플로우를 6.0 Astra로 바꾼다고 설명한다. 이는 제작자 진술이다. 해당 글만으로 이미지/동영상 모델, Blender 사용, 리그·어셋·음성 도구를 알 수 없다. 특정 모델을 그 채널의 실제 렌더러라고 단정하지 않는다.

최신 목록 12개 제목도 확인했으나 모든 영상을 봤다고 하지 않는다. 위 시점은 재생 중 읽은 currentTime 근사값이며 스크린샷 획득 시점과 약간 다를 수 있다. 음성은 음소거 상태여서 나레이션 텐션·억양·정확한 컷 간격은 평가하지 않았다. 석촌호수 편 댓글에는 속도가 빨라 반복 시청한다는 취지의 반응도 있었다. 단일 댓글을 전체 시청자의 선호나 반복 재생 성과로 일반화하지 않는다.

## 적용과 비적용

채택할 것은 **설명 대상 고정, 문제 지점 근접, 상태 변화, 필요한 경우 단면으로 숨은 관계 공개, 같은 세계의 맥락 유지**다. 이 채널의 모든 화면을 미니어처라고 규정하지 않는다. 우리의 미니어처 기본값은 사용자가 선택한 NVIDIA v2와 최신 지시에서 온다.

채널의 과장된 지형/균열/붕괴를 금융 관계에 그대로 복사하지 않는다. 공개 이미지가 사실적이어도 사건의 진실성은 별도 검증한다. 조회수와 도구 이름을 모방하기보다 우리 대본의 행위자·행동·결과를 직접 연출한다. 비공개 제작 방법을 알아냈다거나 같은 성과를 재현할 수 있다고 주장하지 않는다.

현재 실무 기준은 [story-aligned-miniatures.md](story-aligned-miniatures.md)에 있다. 생성 모델 연구부터 다시 시작하는 대신 NVIDIA v2의 설명력을 보존하고, 회사별 관계를 먼저 콘티와 짧은 동작으로 검증한다.
