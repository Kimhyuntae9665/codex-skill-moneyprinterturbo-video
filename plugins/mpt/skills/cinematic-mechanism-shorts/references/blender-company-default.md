# 기본 제작: 쉬운 회사 이야기 × Blender × 원격 GPU

2026-09-06 사용자 명시 지시. 소재의 난이도와 화면의 제작 품질은 독립된 축이다. 기본 콘텐츠는 가볍게 들리는 회사 이야기이며, 기본 화면은 Blender 3D다. 이전의 '사업 관계니까 2D가 더 맞다'는 자동 판단을 반복하지 않는다.

## 실행 순서

1. 기존 easy-company-stories의 쉬운 주제·실제 소셜 반응·사실/시장 해석 기준을 통과한다.
2. 먼저 story-visual-map.md로 주체/역할/행동/결과를 연결한 뒤 서로 다른 3D 연출안 세 가지를 비교한다. 계약 책상, 회사 작업실, 서비스 점포, 고객의 이동, 거래의 결과처럼 내용에 맞는 공간·사건을 설계한다. 새 카메라 각도만으로 장면을 늘리지 않는다.
3. 원격 접속은 현재 로컬의 `~/.codex/local/remote-gpu.sshconfig`와 `remote-gpu.md`를 읽어 사용한다. 사용자가 지정한 게이트웨이→GPU 서버 순서를 존중한다. 이전 직접 주소나 만료된 포워딩 포트를 반복하지 않는다. 주소·비밀번호·키는 스킬과 배포 자료에 넣지 않는다.
4. 접속·GPU 사용량·RAM·디스크·기존 Blender 경로를 실제 확인한다. 인증 대기까지 포함하는 SSH 배너 시간 제한 때문에 실패했는지 구별한다. 이미 설치된 Blender를 재사용하며, 이번 장면에 필요하지 않은 생성 모델은 설치하지 않는다.
5. 음성과 사건을 함께 설계한 뒤 편집 음성으로 타이밍을 고정한다. 재질·접촉 그림자·입체적 카메라·물체 행동이 보이는 대표 프레임과 가장 어려운 짧은 동작을 원격 GPU에서 먼저 렌더한다. CUDA/OptiX 장치 활성화 기록을 남긴다. 파일만 나왔다고 GPU 사용을 주장하지 않는다.
6. 대표 프레임의 실제 용량으로 전체 저장량과 여유 공간을 계산한다. 고해상도 압축 PNG를 사용하거나 이미 완료된 구간을 인코딩하는 등 해당 작업 자료만 관리한다. 다른 사용자 파일을 지우지 않는다.
7. 전체 3D 렌더, 한국어 자막·정확한 숫자·로고 후합성, BGM/효과음 혼합, 별도 썸네일 출력을 진행한다. 썸네일도 이번 3D 장면을 기반으로 로고와 짧은 대표 문구를 넣는다.
8. 최종 MP4의 전체 디코딩과 컷/동작/겹침을 검사하고, 실제 청취와 정상 속도 재생 여부는 별도로 기록한다. 제작에 쓴 `.blend` 또는 재생성 코드·타임라인·원격 렌더 기록을 보존한다.

## 연결이 안 될 때

실제 실패 메시지와 어느 홉이 실패했는지 확인하고 지정 경로로 재시도한다. 그동안 Blender 장면·콘티·음성·로컬 프리뷰를 진행한다. 원격 장애를 이유로 2D 본편을 완성해 대체하지 않는다. 가능한 작업을 마친 뒤 남은 연결 장애를 구체적으로 알린다.

## 화면 수락 기준

최신 기준은 `story-aligned-miniatures.md`다. NVIDIA v2의 내용-화면 대응을 유지하며 정교한 미니어처로 발전시킨다. 과거 목각 인물/미완성 공간의 반려는 모든 미니어처의 금지가 아니다. 후속 실사풍 Amazon도 사업 관계를 보여주지 못해 반려됐다. 따라서 일반 사무실·서버실·인물 클립은 이름만 관련 있다는 이유로 핵심 설명에 사용할 수 없다. 실사 혼합은 향후 명시된 룩 요청에서만 검토하며 내용-그림 일치 검수를 우회하지 않는다.

- 실제 입체 공간, 재질과 깊이, 바닥/책상/벽과 물체의 접촉이 보인다.
- 이야기의 핵심 사건이 물체나 인물의 행동으로 진행된다. 카메라 이동만 달라지는 정지 세트는 부족하다.
- 투자/지출 약속/이익 등 서로 다른 관계를 같은 돈이 확실히 회수되는 장면으로 합치지 않는다.
- 초보자에게 쉬운 대본은 유지한다. Blender를 쓴다는 이유로 서버·칩 내부 설명을 다시 집어넣지 않는다.
