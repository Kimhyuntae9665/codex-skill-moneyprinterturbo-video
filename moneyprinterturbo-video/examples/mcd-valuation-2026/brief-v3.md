# v3 제작 브리프

기준일은 미국 시장 2026-08-27 종가와 McDonald's 2026 Q2 공시다. v2의
가맹·임대료·로열티 설명은 유지하되, 화면 위계를 `현금 엔진 → 주주환원 →
시장 민감도`로 다시 배열한다.

## 메시지

- 최근 6개월 주가와 최근 5년 P/E는 낮아졌지만 역사적 바닥이라고 단정하지 않는다.
- 임대료·로열티 기반 가맹 매출은 주주환원을 설명할 수 있는 반복 현금원천이지만
  매출 자체가 이익이나 FCF는 아니다.
- TTM 현금 주주환원률은 배당과 순현금 자사주매입을 현재 시가총액으로 나눈
  계산값이며 회사가 공시한 공식 비율이 아니다.
- MCD의 과거 베타와 QQQ 상관계수는 기술주 성향 자산과 다른 움직임을 보였다는
  근거지만 미래 분산효과를 보장하지 않는다.

## v3 디자인 시스템

기존 carbon·bone·brass·brick red 팔레트에 시장 비교용 electric cyan
`#46C7F4`와 muted gold `#D5A66F`를 추가한다. 화면은 정적인 카드 대신 다음
요소를 사용한다.

- 실제 매장 사진 위 얇은 건축 그리드와 느린 패럴랙스
- 대각선 마스크, 라인 스윕, 숫자 카운터처럼 보이는 짧은 계층 전환
- 배당과 순매입을 한 원으로 합치는 이중 원호형 shareholder-return dial
- MCD·SPY·QQQ의 베타를 직접 라벨한 세로형 market-sensitivity rails
- MCD와 QQQ의 낮은 상관을 보여주는 두 개의 분리된 파형과 연결 계수
- 정렬 기준선, 동일한 숫자 폭, 한 화면 한 결론, 하단 자막 안전영역 유지

화려함은 데이터의 구조와 전환에서 만들고, 장식용 아이콘·코인·바운스·과도한
글로우는 사용하지 않는다. 오른쪽 Shorts 인터페이스 영역과 하단 약 300px는
핵심 정보에서 제외한다.

## 계산 경계

현금 주주환원은 `FY2025 + H1 2026 - H1 2025`로 TTM을 구성한다.

- 배당: 5.115 + 2.640 - 2.530 = 5.225B달러
- 자사주 매입 현금유출: 2.056 + 1.251 - 0.982 = 2.325B달러
- 옵션 행사 현금유입: 0.285 + 0.142 - 0.188 = 0.239B달러
- 순현금 자사주매입: 2.325 - 0.239 = 2.086B달러
- 총 현금 주주환원: 5.225 + 2.086 = 7.311B달러
- 시가총액 근사: 707,641,531주 × 260.06달러 = 184.029B달러
- 현금 주주환원률: 7.311 / 184.029 = 3.9727%, 영상 표시 `약 4.0%`

비현금 주식보상 희석 전체를 포착하지 못하므로 `순자사주매입`은 영상과 문서에서
반드시 `순현금` 또는 각주가 붙은 표현으로 쓴다.

베타와 상관계수는 Yahoo Finance의 주간 수정주가 262개와 단순 주간 수익률
261개를 사용한다. 기간 요청은 2021-08-27~2026-08-27이며 실제 주간 앵커는
2021-08-23~2026-08-24다. SPY를 S&P 500 투자 프록시, QQQ를 Nasdaq-100
대형 성장주 프록시로 사용한다.
